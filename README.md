# ikey-privacy

아이키(iKey) 공개 사이트 — https://ikey.rapa.world (앱 소스는 `fready-hub/ikeyhome`)

| 경로 | 내용 |
|---|---|
| `index.html` | 앱 소개 랜딩 (구성은 코코세이버 사이트와 같다) |
| `privacy.html` | 개인정보처리방침 — **스토어에 등록된 주소**, 파일명을 바꾸지 않는다 |
| `manual/` | 사용 설명서 — 화면 사진은 `ikeyhome` 의 `bash scripts/ios_sim_screens.sh integration_test/manual_screenshots_test.dart` 로 찍어 536px webp 로 줄인다 |
| `download/` | QR·공유용: 기기에 맞는 스토어로 보낸다. `og.png`(1024×500)·`qr.png` |
| `img/` | 아이콘(256)과 스크린샷(webp) — 원본은 `ikeyhome/docs/store/appstore/` |
| `app-ads.txt` | AdMob 지면 인증 — 도메인 루트에 있어야 한다 |
| `CNAME` | 호스트 설정. 손대지 않는다 |

저장소 이름을 바꾸지 않는다 — 옛 `fready-hub.github.io/ikey-privacy/` 리다이렉트가 끊긴다.
